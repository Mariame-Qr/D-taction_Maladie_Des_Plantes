⚠️  À SAVOIR

1. Modèle TensorFlow Lite
   → Vous DEVEZ fournir model.tflite
   → Format: .tflite (optimisé pour mobile)
   → Taille recommandée: < 100 MB

2. Google Gemini API (optionnel)
   → Améliore les solutions recommandées
   → Gratuit (avec limite d'appels)
   → Adresse: https://ai.google.dev

3. Mode Local vs API
   → Mode Local: TFLite embarqué (rapide, pas de serveur)
   → Mode API: Backend FastAPI (plus puissant, nécessite serveur)

4. Configuration URL
   → Émulateur Android: http://10.0.2.2:8000
   → Appareil physique: http://<votre-IP>:8000
   → PC local: http://localhost:8000

❓ QUESTIONS FRÉQUENTES

Q: Dois-je un serveur pour que ça marche?
A: Non, mode local fonctionne sans serveur. Mode API nécessite le backend.

Q: Comment ajouter mon modèle TensorFlow?
A: 1. Convertir en .tflite si nécessaire
   2. Placer dans assets/model.tflite
   3. Créer assets/labels.txt avec classes

Q: Où est la documentation détaillée?
A: STARTUP.md → guide complet avec toutes les étapes

Q: Comment configurer Gemini?
A: 1. https://ai.google.dev → créer compte
   2. Générer clé API
   3. Modifier lib/config/api_constants.dart

Q: Ça marche sur iOS?
A: Code existe, mais non testé. Même architecture qu'Android.
